# Shareable pages

Self-contained HTML copies of the community guides (open in any browser, send as a file). The Markdown files are
the source; regenerate a page after editing its guide with `tools/md2page.py` (for example `python -I
tools/md2page.py docs/WHERE_IS_EVERYTHING.md docs/share/cr_model_guide.html out.html`: the second file gives the style).
